# SYK studio — Agency Website
this is of freelancing never make this repo PUBLIC

Responsive static site. No framework or build step required.

## Preview locally
Open `index.html` in your browser (or use VS Code Live Server).

## Before publishing
1. Replace `hello@sykstudio.example` in `script.js` with your real agency email.
2. Add team portraits with exact filenames:
   - `assets/kishan.jpg`
   - `assets/sanjana.jpg`
   - `assets/yugandhar.jpg`
3. Confirm all claims and text reflect your actual capabilities.
4. The salon portfolio project is correctly labeled as an independent *concept*, not paid client work.
5. Optionally add your social media links and final brand logo.

## Deploy to Cloudflare Pages
Upload the contents of this folder as a static site using Direct Upload (or connect your GitHub repository). `index.html` must be at the publish root. There is no build command; publish directory is `/` if these files are the repository root.

## Deploy to GitHub Pages
Upload files at the repo root. Go to Settings → Pages → Deploy from a branch → main / (root).

## Notes
- Navigation and copy-email buttons work in modern browsers (clipboard permissions can vary).
- Contact uses email `mailto:`; no form backend or database is included.
- Fonts require an internet connection. The site falls back to system fonts.
